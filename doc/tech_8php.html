Detailed Description

Page technique — démonstration des API JSON (Ghibli) et XML (ip2location).

Cette page illustre la consommation d'APIs externes en PHP :

  • API Studio Ghibli (JSON) : affichage d'un film aléatoire avec images, titre japonais (lang="ja"), année de sortie et description.
  • API ipinfo.io (JSON) : géolocalisation approximative du visiteur par IP.
  • API ip2location.io (XML) : géolocalisation via SimpleXML (format XML). Un rafraîchissement de la page provoque l'affichage d'un nouveau film.
